Laboratorium 1: HTML5, CSS i Flask

Sekcje 1–5 · HTML5, CSS, Flask i wspólny szablon

Cel tej sekcji

Przygotujesz stronę główną osobistej witryny. Wpiszesz własną treść, otworzysz dokument w przeglądarce i sprawdzisz, jak znaczniki HTML opisują strukturę strony. Możesz przedstawić siebie, fikcyjną postać albo wybrany temat. Nie musisz podawać prawdziwych danych osobowych.

To pierwszy etap laboratorium: HTML5 → CSS → Flask → Dockerfile → Docker Compose → GitHub. W tej sekcji pracujemy wyłącznie z HTML. Podstrony uzupełnimy w następnym etapie.

1. Przygotuj katalog projektu

Utwórz katalog personal-website. W Visual Studio Code wybierz File → Open Folder i otwórz ten katalog. Następnie utwórz cztery puste pliki:

personal-website/
├── index.html
├── about.html
├── interests.html
└── style.css
Plik Przeznaczenie
index.html Strona główna z powitaniem
about.html Podstrona „O mnie”
interests.html Podstrona „Zainteresowania”
style.css Wspólny arkusz stylów, używany w kolejnej sekcji

Nazwa index.html jest zwyczajową nazwą strony domyślnej w katalogu witryny. Sprawdź rozszerzenia plików: index.html.txt nie jest plikiem index.html.

2. Wpisz kompletny dokument HTML5

Otwórz index.html i wprowadź poniższy kod. Przycisk kopiowania w prawym górnym rogu bloku pozwala skopiować cały przykład.

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Jan Kowalski — strona osobista</title>
</head>
<body>
    <header>
        <h1>Jan Kowalski</h1>
        <p>Witaj na mojej stronie internetowej!</p>
    </header>

    <nav aria-label="Nawigacja główna">
        <ul>
            <li><a href="index.html">Strona główna</a></li>
            <li><a href="about.html">O mnie</a></li>
            <li><a href="interests.html">Zainteresowania</a></li>
        </ul>
    </nav>

    <main>
        <section>
            <h2>Moja pierwsza strona</h2>
            <p>
                Uczę się projektowania aplikacji internetowych.
                Na tej stronie przedstawiam siebie i swoje zainteresowania.
            </p>
            <p>
                W kolejnych etapach dodam style CSS,
                a następnie uruchomię stronę jako aplikację Flask.
            </p>
        </section>
    </main>

    <footer>
        <p>Autor: Jan Kowalski</p>
    </footer>
</body>
</html>

Zapisz plik: Ctrl+S w Windows/Linux lub Cmd+S w macOS.

3. Zrozum szkielet dokumentu

Znaczniki i elementy

HTML opisuje strukturę i znaczenie treści. Zwykle element składa się ze znacznika otwierającego, treści i znacznika zamykającego:

<p>Witaj na mojej stronie!</p>

<p> rozpoczyna akapit, a </p> go zamyka. Ukośnik oznacza znacznik zamykający. Nie wszystkie elementy mają znacznik zamykający: przykładowo meta go nie ma.

Elementy mogą zawierać inne elementy. Wcięcia pokazują to zagnieżdżenie i ułatwiają czytanie kodu. Zamykaj elementy w odwrotnej kolejności do ich otwierania.

Typ dokumentu i język

<!DOCTYPE html>
<html lang="pl">

Deklaracja <!DOCTYPE html> uruchamia standardowy tryb interpretacji HTML w przeglądarce. Element html obejmuje dokument. Atrybut lang="pl" określa język treści, co pomaga między innymi czytnikom ekranu.

Atrybut to dodatkowa informacja zapisana w znaczniku otwierającym. W tym przykładzie nazwą atrybutu jest lang, a jego wartością pl.

Metadane w head

Fragment Znaczenie
<meta charset="UTF-8"> Deklaruje kodowanie znaków. Sam plik również zapisz jako UTF-8.
<meta name="viewport" content="width=device-width, initial-scale=1.0"> Ustawia obszar wyświetlania zgodnie z szerokością urządzenia.
<title>Jan Kowalski — strona osobista</title> Określa tytuł dokumentu widoczny na karcie przeglądarki.

head zawiera metadane. Widoczną treść umieszczamy w body. Ustawienie viewport przyda się przy tworzeniu układu na telefon; samo nie zapewnia jeszcze responsywności.

Semantyczny podział body

Element Rola w naszej stronie
header Imię i nazwisko oraz powitanie
nav Główna nawigacja
main Główna treść dokumentu
section Tematycznie spójny fragment z własnym nagłówkiem
footer Informacja o autorze

W naszym dokumencie używamy jednego widocznego elementu main. Elementy semantyczne opisują przeznaczenie treści. Wygląd nadamy im później przez CSS.

Nagłówki i akapity

h1 to główny nagłówek strony. h2 oznacza nagłówek sekcji, a p akapit. Dobieraj poziom nagłówka według hierarchii treści, a nie rozmiaru liter.

AdnotacjaTytuł karty a nagłówek strony

Zmień sam title, zapisz plik i odśwież przeglądarkę. Zmieni się podpis karty. Zmiana h1 zmieni nagłówek w treści dokumentu. To dwa różne elementy.

4. Przeanalizuj nawigację

<a href="about.html">O mnie</a>

Element a tworzy odnośnik. Atrybut href podaje jego cel, a tekst między znacznikami jest etykietą widoczną na stronie.

Adres about.html jest ścieżką względną. Przeglądarka szuka pliku w tym samym katalogu co bieżący dokument. Dlatego wszystkie trzy pliki HTML umieszczamy obok siebie.

Menu zapisaliśmy jako listę: ul to lista nieuporządkowana, a każdy li jest jej pozycją. Atrybut aria-label nadaje obszarowi nawigacji nazwę dla technologii wspomagających.

WażnePodstrony są jeszcze puste

Kliknięcie „O mnie” lub „Zainteresowania” otworzy pusty dokument, jeżeli utworzyłeś odpowiedni pusty plik. To oczekiwany stan tego etapu. Wróć przyciskiem Wstecz; zawartość podstron dodamy w kolejnej sekcji.

5. Otwórz stronę w przeglądarce

  1. Znajdź index.html w menedżerze plików.
  2. Otwórz go w przeglądarce lub przeciągnij do jej okna.
  3. Sprawdź tytuł karty, nagłówek, menu, akapity i stopkę.

Adres rozpoczynający się od file:/// oznacza odczyt lokalnego pliku. Nie działa tu jeszcze serwer HTTP ani aplikacja Flask.

Strona będzie miała domyślny wygląd przeglądarki. Menu może być pionową listą z punktami. Plik style.css jest pusty i nie został jeszcze podłączony.

6. Uzupełnij własną treść

Zastąp przykładowe dane własnymi lub wymyślonymi. Zmień:

  • tytuł dokumentu w title;
  • imię i nazwisko w h1 oraz stopce;
  • powitanie w nagłówku;
  • nagłówek sekcji i dwa akapity opisu.

Zachowaj strukturę dokumentu. Samodzielnie zdecyduj, jaki temat rozwiniesz na podstronie „Zainteresowania”. Napisz kilka zdań, które go zapowiadają.

Po każdej zmianie zapisz plik i odśwież przeglądarkę: Ctrl+R lub Cmd+R. Samo wpisanie tekstu w edytorze nie zmienia pliku na dysku.

7. Wykonaj dwa eksperymenty

Nowa linia w kodzie a nowy akapit

Zastąp jeden akapit poniższym fragmentem:

<p>
    Pierwsze zdanie.
    Drugie zdanie.
    Trzecie zdanie.
</p>

Zapisz plik i sprawdź efekt. Przy domyślnym sposobie wyświetlania przeglądarka traktuje przejścia do nowego wiersza i serie spacji jak pojedynczy odstęp. Tekst zawija się zależnie od dostępnej szerokości.

Następnie porównaj z trzema osobnymi akapitami:

<p>Pierwszy akapit.</p>
<p>Drugi akapit.</p>
<p>Trzeci akapit.</p>

Znaczenie wyróżnienia

Wstaw do jednego akapitu element strong:

<p>
    Na tych zajęciach tworzę
    <strong>własną stronę internetową</strong>.
</p>

strong oznacza treść o dużej wadze i domyślnie jest wyświetlany pogrubieniem. Zwróć uwagę: zamykamy strong przed zamknięciem otaczającego go p.

8. Sprawdź rezultat

To lista kontrolna wykonania zadania, nie punktowany test.

Jeżeli widzisz sam kod zamiast strony, sprawdź rozszerzenie pliku i upewnij się, że otwierasz go w przeglądarce. Jeżeli widzisz poprzednią treść, zapisz plik i sprawdź, czy edytujesz ten sam dokument, który jest otwarty w przeglądarce.

Rezultat: masz stronę główną z własną treścią. Następny etap to uzupełnienie dwóch podstron i sprawdzenie nawigacji między nimi.

Sekcja 2. Dwie podstrony i nawigacja

W pierwszym etapie powstała strona główna. Teraz uzupełnisz about.html i interests.html, a następnie sprawdzisz przechodzenie między trzema dokumentami. Nadal nie używamy CSS ani Flaska.

Docelowo wszystkie trzy pliki mają znajdować się w jednym katalogu:

personal-website/
├── index.html
├── about.html
├── interests.html
└── style.css

1. Przygotuj stronę „O mnie”

Otwórz pusty plik about.html i wpisz cały poniższy dokument. Nie wklejaj go do index.html: każda podstrona jest osobnym plikiem z własnym head i body.

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>O mnie — Jan Kowalski</title>
</head>
<body>
    <header>
        <h1>Jan Kowalski</h1>
        <p>Moja osobista witryna internetowa</p>
    </header>

    <nav aria-label="Nawigacja główna">
        <ul>
            <li><a href="index.html">Strona główna</a></li>
            <li><a href="about.html" aria-current="page">O mnie</a></li>
            <li><a href="interests.html">Zainteresowania</a></li>
        </ul>
    </nav>

    <main>
        <section>
            <h2>O mnie</h2>
            <p>
                Jestem studentem i uczę się tworzyć aplikacje internetowe.
                Lubię poznawać nowe narzędzia i sprawdzać je w praktyce.
            </p>
            <p>
                Moim celem na te zajęcia jest przygotowanie własnej witryny
                i uruchomienie jej w kontenerze.
            </p>

            <h3>Czego chcę się nauczyć?</h3>
            <ul>
                <li>Budowania stron w HTML5.</li>
                <li>Opisywania wyglądu za pomocą CSS.</li>
                <li>Tworzenia aplikacji we Flasku.</li>
            </ul>

            <p>
                Materiały do samodzielnej nauki znajdziesz w
                <a href="https://developer.mozilla.org/pl/docs/Web/HTML">dokumentacji HTML w MDN</a>.
            </p>
        </section>
    </main>

    <footer>
        <p>Autor: Jan Kowalski</p>
    </footer>
</body>
</html>

Zapisz plik i otwórz go w przeglądarce. Możesz również przejść do niego przez odnośnik „O mnie” na stronie głównej.

2. Przeanalizuj różnice względem strony głównej

Szkielet dokumentu pozostaje taki sam. Zmieniliśmy tytuł karty, treść main i oznaczenie bieżącej pozycji menu.

Fragment Dlaczego go zmieniamy?
title Pozwala rozpoznać podstronę na karcie przeglądarki.
h2 w main Wskazuje temat bieżącej podstrony.
Akapity i lista Zawierają treść właściwą dla strony „O mnie”.
aria-current="page" Oznacza odnośnik prowadzący do aktualnie otwartej strony.

Nazwisko w h1, menu i stopka pozostają wspólne dla całej witryny. Pod nagłówkiem sekcji h2 umieściliśmy nagłówek niższego poziomu h3, opisujący listę celów.

Lista ul grupuje elementy, których kolejność nie jest istotna. Każda pozycja musi znajdować się we własnym elemencie li.

AdnotacjaBieżąca strona w menu

aria-current="page" przekazuje informację o bieżącej stronie technologiom wspomagającym. Sam atrybut nie zmienia domyślnie wyglądu odnośnika. Wyróżnienie wizualne dodamy w CSS.

3. Przygotuj stronę „Zainteresowania”

Otwórz interests.html i wpisz kompletny dokument:

<!DOCTYPE html>
<html lang="pl">
<head>
    <meta charset="UTF-8">

<body>
    <header>
        <h1>Jan Kowalski</h1>
        <p>Moja osobista witryna internetowa</p>
    </header>

    <nav aria-label="Nawigacja główna">
        <ul>
            <li><a href="index.html">Strona główna</a></li>
            <li><a href="about.html">O mnie</a></li>
            <li><a href="interests.html" aria-current="page">Zainteresowania</a></li>
        </ul>
    </nav>

    <main>
        <section>
            <h2>Moje zainteresowania</h2>
            <p>

            <h3>Jak przygotowuję zdjęcia do galerii?</h3>
            <ol>
                <li>Wybieram zdjęcia z wyjazdu.</li>
                <li>Przygotowuję krótki opis każdego zdjęcia.</li>

Zapisz plik. Tutaj użyliśmy ol, czyli listy uporządkowanej: kolejność kroków ma znaczenie. Jej pozycje również zapisujemy jako li.

Zastąp fotografię dowolnym własnym tematem. Zachowaj dwa akapity, nagłówek listy, listę i odnośnik zewnętrzny. Jeśli opisujesz zbiór zainteresowań bez określonej kolejności, możesz zamienić ol na ul, zmieniając oba znaczniki: otwierający i zamykający.

4. Ujednolić menu na stronie głównej

W index.html znajdź cały element nav i zastąp go poniższym fragmentem:

<nav aria-label="Nawigacja główna">
    <ul>
        <li><a href="index.html" aria-current="page">Strona główna</a></li>
        <li><a href="about.html">O mnie</a></li>
        <li><a href="interests.html">Zainteresowania</a></li>
    </ul>
</nav>

W każdym pliku menu zawiera te same etykiety, adresy i kolejność odnośników. Różni się położeniem aria-current="page":

Dokument Odnośnik oznaczony jako bieżący
index.html Strona główna
about.html O mnie
interests.html Zainteresowania

W każdym z tych menu oznacz dokładnie jedną pozycję jako bieżącą. Nie przenoś menu z about.html do pozostałych plików bez poprawienia tego oznaczenia.

5. Rozróżnij rodzaje adresów

Porównaj trzy zapisy:

<a href="about.html">O mnie</a>
<a href="https://developer.mozilla.org/pl/docs/Web/HTML">Dokumentacja HTML</a>
<a href="#top">Początek strony</a>
Adres Działanie
about.html Otwiera dokument względem katalogu bieżącej strony.
https://developer.mozilla.org/pl/docs/Web/HTML Otwiera wskazany adres w internecie.
#top Przechodzi do elementu o id="top" w bieżącym dokumencie.

Aby wypróbować trzeci wariant, dodaj id="top" do istniejącego nagłówka strony:

<header id="top">
    <h1>Jan Kowalski</h1>
    <p>Moja osobista witryna internetowa</p>
</header>

Następnie dodaj odnośnik „Początek strony” do stopki. Na krótkim dokumencie przewinięcie może być niezauważalne, ale w adresie pojawi się fragment #top. Wartość id musi być unikalna w obrębie dokumentu.

WażneDlaczego bez ukośnika na początku?

W tym ćwiczeniu zapisuj href="about.html", a nie href="/about.html". Początkowy ukośnik oznacza ścieżkę od korzenia bieżącego adresu. Przy otwieraniu lokalnych plików nie wskazuje katalogu projektu; na serwerze wskazuje korzeń witryny. Może więc prowadzić do innego miejsca niż oczekujesz.

Nie wpisuj też ścieżek do własnego dysku, takich jak C:\Users\Jan\.... Menu ma działać również po przeniesieniu całego katalogu na inny komputer.

Odnośniki z przykładów otwierają dokumenty w tej samej karcie. Przycisk Wstecz w przeglądarce pozwala wrócić do poprzednio odwiedzonej strony.

6. Samodzielnie uzupełnij treść

Na obu podstronach ustaw tę samą nazwę autora co na stronie głównej. Napisz własne akapity i zmień pozycje list. Dobierz odnośnik zewnętrzny związany z tematem i nadaj mu etykietę opisującą cel, np. „Dokumentacja HTML w MDN”, zamiast samego „Kliknij tutaj”.

Nie zmieniaj nazw plików, chyba że poprawisz również wszystkie prowadzące do nich odnośniki. Zachowaj wspólną strukturę nagłówka, menu i stopki.

7. Sprawdź wszystkie przejścia

Otwórz index.html. Sprawdź poniższe przejścia, za każdym razem używając menu:

Z dokumentu Przejdź do Oczekiwany plik
Strona główna O mnie about.html
O mnie Zainteresowania interests.html
Zainteresowania Strona główna index.html
Strona główna Zainteresowania interests.html
Zainteresowania O mnie about.html
O mnie Strona główna index.html

Po każdym przejściu sprawdź adres, tytuł karty i nagłówek treści. Dzięki temu upewnisz się, że odnośnik otwiera właściwy dokument, a nie tylko stronę o podobnym wyglądzie.

Przetestuj również menu klawiaturą: użyj Tab, aby przejść do odnośnika, i Enter, aby go otworzyć. Sprawdź, czy widzisz obramowanie wskazujące aktualnie wybrany odnośnik.

8. Jeśli nawigacja nie działa

Objaw Co sprawdzić?
Przeglądarka nie znajduje pliku Czy plik istnieje w tym samym katalogu i ma nazwę podaną w href?
Otwiera się pusta strona Czy zapisano zawartość właściwego pliku?
Menu prowadzi do innej podstrony Czy etykieta i href opisują tę samą stronę?
Lokalnie działa, po przeniesieniu przestaje Czy nie użyto ścieżki do własnego dysku lub innej wielkości liter?
Tytuł karty jest taki sam wszędzie Czy zmieniono title w każdym dokumencie?

Zachowuj identyczną wielkość liter w nazwach plików i adresach. About.html i about.html mogą być różnymi plikami na serwerze, nawet jeśli lokalny system ich nie rozróżnia.

9. Punkt kontrolny sekcji 2

Rezultat: masz kompletną statyczną witrynę z trzema stronami. W kolejnym etapie podłączysz wspólny arkusz CSS. Powtarzający się kod menu pozostaje na razie w trzech plikach; później przeniesiemy go do wspólnego szablonu Flaska.

Sekcja 3. Podstawy CSS i wspólny arkusz stylów

Masz już trzy dokumenty HTML połączone menu. Teraz nadasz im wspólny wygląd. Utworzysz jeden arkusz CSS, podłączysz go do każdej strony i sprawdzisz, czy zmiana jednej reguły wpływa na całą witrynę.

HTML nadal opisuje strukturę i znaczenie treści. CSS określi między innymi kolory, krój pisma, odstępy i układ menu.

1. Podłącz arkusz do trzech dokumentów

W każdym pliku — index.html, about.html i interests.html — dodaj poniższy element wewnątrz head, po title:

<link rel="stylesheet" href="style.css">

Dla strony głównej kompletny fragment head będzie wyglądał tak:

<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

Na podstronach zachowaj ich własne tytuły. Dodaj wyłącznie odwołanie do arkusza.

rel="stylesheet" określa, że podłączony zasób jest arkuszem stylów. href="style.css" wskazuje plik w tym samym katalogu co dokument. Element link nie ma znacznika zamykającego.

5. Przeanalizuj typografię i dziedziczenie

W regule body ustawiliśmy wspólne właściwości tekstu:

body {
    font-family: Arial, Helvetica, sans-serif;
    font-size: 1rem;
    line-height: 1.6;
}

Przeglądarka próbuje użyć Arial, potem Helvetica, a następnie dostępnej czcionki bezszeryfowej. Lista pozwala wyświetlić tekst również na komputerze bez pierwszej z podanych czcionek.

Jednostka rem odnosi się do rozmiaru czcionki elementu głównego html. Przy typowych ustawieniach 1rem odpowiada 16 pikselom, ale użytkownik może zmienić te ustawienia. line-height: 1.6 określa wysokość wiersza jako 1,6 rozmiaru czcionki danego elementu.

Wiele właściwości tekstu, w tym krój pisma i kolor, jest dziedziczonych przez elementy potomne. Nie musimy więc osobno przypisywać czcionki każdemu akapitowi. Reguły dla nagłówków i odnośników mogą nadpisywać wybrane wartości.

6. Zrozum odstępy i szerokość

Każdy element jest opisywany przez model pudełkowy: treść, wewnętrzny odstęp padding, obramowanie border i zewnętrzny odstęp margin.

Właściwość Zastosowanie w przykładzie
padding: 1.5rem Odsuwa treść sekcji od jej obramowania.
border: 1px solid #cbd5e1 Tworzy cienką, ciągłą ramkę sekcji.
margin-bottom: 1rem Dodaje odstęp pod sekcją.
max-width: 60rem Ogranicza szerokość głównych obszarów na dużym ekranie.
margin: 0 auto Ustawia zerowy margines pionowy i automatyczne marginesy poziome.

Przy szerokości ograniczonej przez max-width automatyczne marginesy poziome wyśrodkowują obszar. Na małym ekranie width: 100% pozwala wykorzystać dostępną szerokość.

Na początku arkusza ustawiliśmy box-sizing: border-box dla wszystkich elementów za pomocą selektora *. Dzięki temu zadeklarowana szerokość obejmuje również padding i obramowanie. Ułatwia to utrzymanie elementów w granicach ekranu.

Eksperyment: zmień padding w main section z 1.5rem na 0. Sprawdź, jak tekst zbliża się do ramki. Następnie przywróć poprzednią wartość. Porównaj z ustawieniem margin-bottom: 0, które zmienia odstęp na zewnątrz sekcji.

Selektor Co wybiera?
body Element body.
header, nav, main, footer Cztery rodzaje elementów objęte wspólną regułą.
header p Akapity znajdujące się wewnątrz nagłówka strony.
nav a Odnośniki wewnątrz nawigacji.
nav a[aria-current="page"] Odnośnik menu z podaną wartością atrybutu.
a:hover Odnośnik wskazywany kursorem.

Spacja w nav a oznacza potomka: odnośnik nie musi być bezpośrednim dzieckiem nav. W naszym HTML między nimi znajdują się jeszcze ul i li.

Reguła main section > h2:first-child wybiera nagłówek h2, który jest pierwszym dzieckiem sekcji wewnątrz main. Usuwa jego górny margines, pozostawiając odstęp kontrolowany przez padding sekcji.

O wyniku decyduje kaskada. W naszym arkuszu, dla deklaracji o tym samym pochodzeniu i poziomie ważności, bardziej szczegółowy selektor wygrywa z mniej szczegółowym. Przy takiej samej szczegółowości wygrywa deklaracja zapisana później.

Przykładowo nav a usuwa podkreślenie menu, choć przeglądarka domyślnie podkreśla odnośniki. Reguła nav a[aria-current="page"] przywraca je dla bieżącej strony i ustawia jej tło. Dzięki temu aktywna pozycja różni się nie tylko kolorem.

8. Zobacz, jak Flexbox układa menu

nav ul {
    display: flex;
    flex-wrap: wrap;
    gap: 0.5rem;
    margin: 0;
    padding: 0;
    list-style: none;
}

display: flex zmienia układ dzieci listy, czyli elementów li. Domyślnie są rozmieszczane w wierszu. gap określa odstępy między nimi, a flex-wrap: wrap pozwala przejść do kolejnego wiersza, gdy brakuje miejsca.

list-style: none usuwa wizualne punkty listy; elementy ul i li nadal pozostają w HTML. Zerujemy także domyślne marginesy i wewnętrzny odstęp listy.

W regule nav a używamy display: block, aby obszar odnośnika wraz z wewnętrznymi odstępami tworzył wyraźne pole do kliknięcia.

Zwęż okno przeglądarki. Menu powinno zawijać się zamiast wymagać sztywnej szerokości strony. Ten prosty układ nie wymaga jeszcze reguł @media.

Sekcja 4. Flask: jedna strona i dwie podstrony

Dotychczas przeglądarka odczytywała pliki z dysku. Teraz uruchomisz aplikację HTTP w Pythonie. Najpierw obsłużysz stronę główną, a następnie dodasz dwie podstrony. Zachowasz własną treść i wspólny arkusz CSS.

1. Przygotuj Pythona i terminal

Otwórz terminal w katalogu personal-website. To katalog Twojej aplikacji, nie repozytorium strony kursu. Korzystamy z Pythona 3.11 lub nowszego. Sprawdź wersję:

macOS / Linux:

python3 --version

Windows (PowerShell):

py -3 --version

Jeżeli interpreter nie jest dostępny, zgłoś to prowadzącemu. Nie instaluj pakietów globalnie i nie używaj sudo.

2. Utwórz izolowane środowisko

macOS / Linux:

python3 -m venv .venv
source .venv/bin/activate

Windows (PowerShell):

py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1

Jeśli PowerShell blokuje aktywację, możesz korzystać bezpośrednio z interpretera środowiska, bez zmiany polityki wykonywania skryptów:

.\.venv\Scripts\python.exe -m pip install Flask

W takim wariancie w następnych poleceniach zastępuj python przez .\.venv\Scripts\python.exe.

Po aktywacji środowiska sprawdź interpreter i zainstaluj Flask:

python -c "import sys; print(sys.executable)"
python -m pip install Flask
python -m pip show Flask

Ścieżka interpretera powinna prowadzić do .venv w Twoim projekcie. Zapis python -m pip wiąże instalację z tym właśnie interpreterem. W edytorze również wybierz interpreter z .venv, jeśli zgłasza brak biblioteki Flask.

Środowisko .venv zawiera lokalną instalację zależności. Nie jest kodem aplikacji i nie należy umieszczać go w repozytorium Git ani kopiować do obrazu Dockera.

3. Uporządkuj pliki aplikacji

Utwórz katalogi templates i static. Przenieś trzy pliki HTML do templates, a style.css do static. W głównym katalogu utwórz app.py:

personal-website/
├── .venv/
├── app.py
├── templates/
│   ├── index.html
│   ├── about.html
│   └── interests.html
└── static/
    └── style.css

Przenoś pliki zamiast zostawiać dodatkowe kopie. app.py musi znajdować się obok katalogów templates i static. Nie nazywaj go flask.py, ponieważ taka nazwa może przesłonić import biblioteki.

Pliki HTML pozostają Twoimi dotychczasowymi dokumentami. Flask będzie je przetwarzać jako szablony. Arkusz CSS pozostaje bez zmian.

4. Napisz aplikację z jedną trasą

Wpisz kompletną zawartość app.py:

from flask import Flask, render_template

app = Flask(__name__)


@app.route("/")
def home() -> str:
    """Render the home page."""
    return render_template("index.html")
Fragment Rola
Flask Klasa, z której tworzymy obiekt aplikacji.
app = Flask(__name__) Tworzy aplikację z informacją o module potrzebną do lokalizowania zasobów.
@app.route("/") Przypisuje adres strony głównej do funkcji poniżej.
home() Funkcja wykonywana przy żądaniu tej strony.
render_template("index.html") Renderuje dokument z katalogu templates.

Adnotacja -> str opisuje typ wartości zwracanej przez naszą funkcję. Nie jest konfiguracją protokołu HTTP.

5. Przygotuj stronę główną do obsługi przez Flask

W templates/index.html zmień odwołanie do CSS na:

<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">

Na razie zastąp całe menu wersją z jednym odnośnikiem:

<nav aria-label="Nawigacja główna">
    <ul>
        <li><a href="{{ url_for('home') }}" aria-current="page">Strona główna</a></li>
    </ul>
</nav>

Nie dodawaj jeszcze url_for('about') ani url_for('interests'). Takie funkcje nie istnieją w aplikacji z jedną trasą. Dodamy je w kolejnym kroku.

Zapis { ... } jest wyrażeniem szablonu Jinja. Serwer oblicza jego wartość przed wysłaniem HTML do przeglądarki. url_for('home') generuje adres na podstawie nazwy funkcji, a url_for('static', filename='style.css') wskazuje zasób statyczny.

W head zachowaj metadane i własny tytuł. Poza CSS i menu nie zmieniaj przygotowanej wcześniej treści.

6. Uruchom pierwszą stronę

W terminalu z aktywnym środowiskiem, pozostając w katalogu z app.py, wykonaj:

python -m flask --app app run --debug

--app app wskazuje moduł app.py. Polecenie run uruchamia serwer deweloperski. Opcja --debug pomaga podczas lokalnych ćwiczeń i automatycznie przeładowuje aplikację po zmianach kodu Pythona.

Otwórz http://127.0.0.1:5000/. Terminal pozostaw uruchomiony. Zatrzymanie procesu przez Ctrl+C wyłącza serwer.

WażneOtwieraj adres HTTP, nie plik szablonu

Od tego etapu korzystaj z adresu serwera. Podwójne kliknięcie templates/index.html nie uruchamia Flaska ani Jinja. Przy adresie file:/// wyrażenia { ... } nie zostaną obliczone.

Tryb debugowania służy do lokalnej pracy laboratoryjnej. Nie udostępniaj go jako publicznego serwera.

Sprawdź stronę główną i otwórz również http://127.0.0.1:5000/static/style.css. Powinien pojawić się kod Twojego arkusza. Adres /about na tym etapie zwróci 404, ponieważ nie dodaliśmy jeszcze takiej trasy.

Jeżeli port jest zajęty, uruchom serwer na innym porcie:

python -m flask --app app run --debug --port 5001

Wtedy we wszystkich adresach używaj portu 5001.

7. Dodaj dwie podstrony

Zastąp app.py poniższą kompletną wersją:

from flask import Flask, render_template

app = Flask(__name__)


@app.route("/")
def home() -> str:
    """Render the home page."""
    return render_template("index.html")


@app.route("/about")
def about() -> str:
    """Render the about page."""
    return render_template("about.html")


@app.route("/interests")
def interests() -> str:
    """Render the interests page."""
    return render_template("interests.html")

Zapisz plik. Przy uruchomionym trybie debugowania serwer powinien przeładować kod. Jeśli został zatrzymany, uruchom go ponownie tym samym poleceniem.

Adres w przeglądarce Funkcja / endpoint Plik szablonu
/ home templates/index.html
/about about templates/about.html
/interests interests templates/interests.html

Nazwa funkcji jest tutaj domyślną nazwą endpointu. Rozróżniaj trzy rzeczy: adres URL, nazwę funkcji oraz nazwę pliku. W przykładzie /about prowadzi do about(), a funkcja renderuje about.html.

8. Podłącz CSS na obu podstronach

W templates/about.html i templates/interests.html zastąp dotychczasowy element link tym samym zapisem co na stronie głównej:

<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">

Nie wpisuj ../static/style.css. Przeglądarka rozwiązuje względne adresy względem adresu dokumentu, a nie położenia szablonu na dysku serwera. url_for() pozwala uniknąć tego pomieszania.

10. Prześledź żądanie i odpowiedź

Kliknij „O mnie” i prześledź kolejne etapy:

  1. Przeglądarka wysyła żądanie GET /about do lokalnego serwera.
  2. Flask dopasowuje trasę i wykonuje about().

  4. Serwer zwraca wynikowy HTML.
  5. Przeglądarka odczytuje odwołanie do CSS i wysyła osobne żądanie GET /static/style.css.

Otwórz źródło strony w przeglądarce i znajdź menu. Powinny być w nim zwykłe adresy /, /about i /interests, bez wyrażeń { url_for(...) }. Kod Pythona i źródło szablonu nie są wysyłane jako kod do wykonania w przeglądarce.

Otwórz /interests Własna treść zainteresowań.
Przejdź między stronami przez menu Każdy odnośnik otwiera właściwą trasę.
Otwórz /static/style.css Kod wspólnego arkusza.
Otwórz /missing Odpowiedź 404, bo takiej trasy nie zdefiniowano.

Obserwuj terminal: zobaczysz żądania oraz ich statusy. 200 oznacza powodzenie, 404 brak wskazanego zasobu, a 500 błąd po stronie aplikacji.

Problem Co sprawdzić?
No module named flask Interpreter i instalację Flask w aktywnym .venv.
TemplateNotFound Pisownię nazwy i obecność pliku w templates obok app.py.
BuildError Czy argument url_for() jest nazwą istniejącego endpointu, np. about, a nie about.html?
Brak stylów Obecność static/style.css i poprawny element link w każdym szablonie.
404 dla /about.html Użyj /about: to adres zdefiniowany w aplikacji.
Brak połączenia Czy serwer działa i czy używasz portu wskazanego w terminalu?

W tych przykładach trasy podstron nie kończą się ukośnikiem. Korzystaj z adresów generowanych przez menu, np. /about, zamiast samodzielnie dopisywać /about/.

12. Samodzielny eksperyment z adresem

Zmień tylko dekorator trasy strony „O mnie”:

@app.route("/about-me")
def about() -> str:
    """Render the about page."""
    return render_template("about.html")

Nie zmieniaj nazwy funkcji ani url_for('about') w menu. Po zapisaniu pliku odśwież stronę główną i kliknij „O mnie”. Adres powinien teraz kończyć się na /about-me. Stary adres /about zwróci 404.

To pokazuje, po co generujemy adresy na podstawie nazw endpointów. Po eksperymencie przywróć trasę /about, aby projekt był zgodny z dalszą instrukcją.

W tym pliku pozostaje cały szkielet dokumentu: od deklaracji HTML po zamknięcie body i html. Arkusz jest podłączony tylko tutaj. Menu i stopka również mają jedno wspólne źródło.

3. Rozróżnij wyrażenia i instrukcje Jinja

Zapis Przeznaczenie
{ url_for('home') } Oblicza wartość i wstawia ją do wynikowego HTML.
{% block content %}...{% endblock %} Definiuje miejsce, którego zawartość może określić szablon potomny.
{% extends "base.html" %} Wskazuje szablon, z którego dziedziczymy strukturę.
{% if ... %}...{% endif %} Warunkowo dodaje fragment dokumentu.

W bazie zdefiniowaliśmy dwa bloki: title i content. Pierwszy znajduje się wewnątrz elementu title, drugi wewnątrz main. Szablony stron wypełnią je własną treścią. Sufiks z nazwiskiem pozostaje poza blokiem title, więc jest wspólny.

7. Zachowaj trzy trasy aplikacji

app.py pozostaje taki jak po poprzedniej sekcji. Dla porównania pełna wersja:

from flask import Flask, render_template

app = Flask(__name__)


@app.route("/")
def home() -> str:
    """Render the home page."""
    return render_template("index.html")


@app.route("/about")
def about() -> str:
    """Render the about page."""
    return render_template("about.html")


@app.route("/interests")
def interests() -> str:
    """Render the interests page."""
    return render_template("interests.html")

Nadal renderujesz szablon konkretnej strony, np. about.html. Jinja odczytuje jego extends, łączy bloki ze strukturą base.html i tworzy kompletny wynikowy dokument. Nie zmieniaj wszystkich wywołań na render_template("base.html"), bo stracisz treść właściwą dla podstron.

8. Zrozum automatyczne oznaczenie menu

W szablonie bazowym sprawdzamy bieżący endpoint:

<a href="{{ url_for('about') }}"{% if request.endpoint == 'about' %} aria-current="page"{% endif %}>O mnie</a>

Podczas obsługi /about wartością request.endpoint jest about. Flask udostępnia obiekt request w szablonie podczas żądania. Warunek dodaje wtedy atrybut aria-current="page". Dla innych stron ten atrybut nie jest dodawany do tego odnośnika.

Spacja przed aria-current wewnątrz warunku oddziela atrybuty w wynikowym HTML. Nasz wcześniejszy CSS nadal odczytuje ten sam atrybut, dlatego nie trzeba zmieniać reguły wyróżnienia menu.

9. Sprawdź współdzielenie i wynikowy HTML

Uruchom serwer, jeśli nie działa:

python -m flask --app app run --debug

Otwórz kolejno /, /about i /interests. Sprawdź własną treść, tytuł karty, CSS i właściwą pozycję menu.

Następnie zmień tekst stopki tylko w base.html. Odśwież wszystkie strony. Nowy tekst powinien pojawić się na każdej z nich.

W źródle strony w przeglądarce sprawdź, czy:

  • występuje jeden szkielet html, head i body;
  • menu i stopka występują po jednym razie;
  • nie ma instrukcji {% extends ... %} ani {% block ... %};
  • właściwy odnośnik ma aria-current="page".

Jeśli treść jest pusta, porównaj nazwy bloków: content i contents to różne nazwy. Jeżeli otrzymasz TemplateNotFound: base.html, sprawdź jego położenie w templates. Przy błędzie TemplateSyntaxError sprawdź domknięcia endblock, endif i nawiasów Jinja.

10. Opcjonalnie: prosty panel Bootstrap

Najpierw uruchom i sprawdź wersję ze swoim CSS. Bootstrap dodamy jako krótki eksperyment: użyjemy gotowego komponentu, zachowując istniejące menu i układ.

W base.html, przed odwołaniem do style.css, dodaj arkusz Bootstrap. Docelowe dwa elementy link:

<link
    href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css"
    rel="stylesheet"
    integrity="sha384-sRIl4kxILFvY47J16cr9ZwB07vP4J8+LH7qKQnuqkuIAvNWLzeN8tE5YBujZqJLB"
    crossorigin="anonymous">
<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">

To arkusz pobierany z internetu. Jego użycie nie wymaga instalacji pakietu Pythona. Przy pracy bez dostępu do sieci pozostań przy wcześniejszej wersji z własnym CSS. Atrybut integrity pozwala przeglądarce zweryfikować pobrany plik; przy zmianie wersji adres i suma muszą pochodzić z tej samej oficjalnej konfiguracji.

W templates/index.html, wewnątrz istniejącej sekcji i bloku content, dodaj:

<div class="alert alert-info" role="note">
    Ta strona korzysta ze wspólnego szablonu Flask.
</div>

<div class="card mt-3">
    <div class="card-body">
        <h3 class="card-title">Poznaj autora</h3>
        <p class="card-text">Przejdź do krótkiego opisu moich zainteresowań.</p>
        <a class="btn btn-primary" href="{{ url_for('interests') }}">
            Zobacz zainteresowania
        </a>
    </div>
</div>

Atrybut class może zawierać kilka klas oddzielonych spacjami. Bootstrap definiuje ich wygląd: card tworzy kartę, card-body jej wnętrze, btn btn-primary wygląd przycisku, a mt-3 górny margines. Odnośnik nadal jest elementem a i nadal prowadzi do trasy Flaska.

Te komponenty nie wymagają JavaScriptu. Nie dodajemy rozwijanego menu ani innych interaktywnych komponentów.

Własny arkusz ładowany jest po Bootstrapie. Przy takiej samej ważności i szczegółowości późniejsza deklaracja może nadpisać wcześniejszą, ale sama kolejność nie gwarantuje nadpisania każdej reguły. Bootstrap zawiera też style ogólne: po podłączeniu sprawdź ponownie wszystkie strony, listy i fokus klawiatury.
